# Отчёт по ГОСТ 7.32-2017

Скилл про **структуру и правила оформления**, а не про формат файла: годится для Word,
Typst, LaTeX и любого другого. Если у вуза или кафедры есть методические указания
(«методичка»), **они главнее ГОСТа** — спроси у пользователя, есть ли они, и где они
расходятся с таблицей ниже, следуй им. Значения ниже — база по ГОСТ 7.32-2017 с поправкой на
то, что чаще всего требуют вузы; там, где вузы расходятся, это помечено.

## Структура

Порядок элементов фиксирован. Обязательные выделены.

1. **Титульный лист** — оформляется по форме вуза/организации, не по свободному вкусу.
2. Список исполнителей — если работа коллективная.
3. **Реферат** — объём (страницы, рисунки, таблицы, источники, приложения), ключевые слова
   (5–15 слов или словосочетаний в именительном падеже, прописными, через запятую, в строку),
   затем текст: объект, цель, методы, результаты, основные выводы.
4. **Содержание** — все структурные элементы и разделы с номерами страниц.
5. Термины и определения; перечень сокращений и обозначений — если их больше нескольких.
6. **Введение** — актуальность, цель и задачи, объект и предмет, методы; для ВКР обычно
   ещё положения, выносимые на защиту / научная новизна / практическая значимость
   (проверь по методичке).
7. **Основная часть** — разделы и подразделы; для обзора литературы это группировка по идеям,
   а не по статьям.
8. **Заключение** — выводы по задачам, ответы на вопросы введения, при необходимости
   направления дальнейшей работы. Новых данных не вводить.
9. **Список использованных источников.**
10. Приложения.

## Оформление страницы

| Параметр | Значение |
|---|---|
| Формат | A4, односторонняя печать |
| Поля | левое 30 мм, правое 10 мм, верхнее и нижнее 20 мм (вузы часто требуют правое 15 мм) |
| Шрифт | Times New Roman (или близкий), 12–14 пт; вузы чаще требуют 14 пт |
| Интервал | полуторный |
| Абзацный отступ | 1,25 см |
| Выравнивание | по ширине, без переносов |
| Нумерация страниц | арабские цифры, внизу по центру, без точки; сквозная; титульный лист считается, но номер на нём не ставится |

## Заголовки и нумерация

- Названия структурных элементов (СОДЕРЖАНИЕ, ВВЕДЕНИЕ, ЗАКЛЮЧЕНИЕ, СПИСОК ИСПОЛЬЗОВАННЫХ
  ИСТОЧНИКОВ, ПРИЛОЖЕНИЕ) — прописными буквами, по центру, без точки, без подчёркивания и
  без нумерации; обычно каждый с новой страницы.
- Разделы нумеруются арабскими цифрами с абзацного отступа, **без точки в конце** номера и
  заголовка: «1 Название раздела». Подразделы: «1.1», «1.1.1». Заголовок не переносится
  по слогам; между заголовком и текстом — пропуск строки.
- Если в разделе один подраздел, его не выделяют; у пункта нумерации внутри подраздела —
  по уровням, не глубже четырёх.

## Иллюстрации, таблицы, формулы

- **Рисунок.** Подпись под рисунком, по центру: «Рисунок 1 – Название». Нумерация сквозная
  (или внутри раздела: «Рисунок 1.1» — как требует методичка). В тексте: «(рисунок 1)». Ссылка
  на рисунок стоит **до** самого рисунка.
- **Таблица.** Название над таблицей, слева, без абзацного отступа: «Таблица 1 – Название».
  Перенос таблицы: «Продолжение таблицы 1» над продолжением; шапку повторяют. В тексте:
  «(таблица 1)».
- **Формула.** С новой строки по центру; номер в круглых скобках у правого поля: (1).
  Пояснения символов — после формулы со слова «где», каждый символ с новой строки или в строку,
  в порядке появления в формуле.
- **Перечисления.** Дефис или строчные буквы со скобкой, внутри — арабские цифры со скобкой;
  принятый в работе знак — единообразно.

## Ссылки и список источников

- Ссылки в тексте — в квадратных скобках: [1], [1, с. 25], [1–3]. Номер — по порядку первого
  упоминания в тексте (так по умолчанию в ГОСТ 7.32); многие вузы требуют алфавитный порядок —
  спроси.
- Библиографическое описание — по ГОСТ Р 7.0.100-2018 (прежнее ГОСТ 7.1-2003 всё ещё
  встречается в методичках). Для статьи: автор, название, журнал, год, том, номер, страницы,
  DOI. Для электронных ресурсов — URL и дата обращения.
- Источник из списка без ссылки в тексте — замечание нормоконтроля; и наоборот.
- Если материал собран в snowcite: `export_bibliography("bibtex")` даёт записи и соответствие
  `id → ключ`; оформи их в нужный ГОСТ-стиль в целевом формате.

## Приложения

Обозначаются заглавными буквами русского алфавита, начиная с А, **кроме Ё, З, Й, О, Ч, Ь, Ы, Ъ**:
«ПРИЛОЖЕНИЕ А», ниже — название. На каждое приложение есть ссылка в тексте. Рисунки и таблицы в
приложениях нумеруются внутри приложения: «Рисунок А.1», «Таблица Б.2».

## Типичные замечания нормоконтроля

- Точки в конце заголовков; переносы в заголовках; заголовок раздела внизу страницы без текста.
- Разный шрифт или интервал в таблицах и основном тексте без причины.
- Рисунок или таблица без ссылки в тексте, ссылка после рисунка, подпись не по форме.
- Нумерация разделов и содержание расходятся; нет страниц в содержании.
- Список источников не по форме, номера не совпадают со ссылками, нет обязательных элементов
  описания (DOI, страницы, год).
- Приложения не обозначены по правилам, нет ссылок на них.
- Разные формы тире и дефиса: в подписях «Рисунок 1 – …» — тире (–) с пробелами.

## Как работать с пользователем

1. Узнай, есть ли методичка; если есть — попроси её или список отличий от ГОСТ.
2. Составь план работы по структуре выше и согласуй до написания текста.
3. Пиши текст по навыку `academic-writing-ru`; секции черни и критикуй через snowcite.
4. Перед сдачей пройди по списку «Типичные замечания» и отдельно сверь список источников со
   ссылками.
