# Начало работы

Первый обзор из пустого каталога.

## 1. Начать проект

```
> Нужен обзор литературы по <тема>, ВКР на русском, ГОСТ 7.32.
```

Claude вызывает `next_step()` → фаза `not_started`, спрашивает профиль проекта (язык, дисциплина, стандарт, при желании автор, вуз, цели) и запускает `init_project`. Рядом с файлами появляется `.snowcite/`; больше ничего не генерируется.

## 2. Критерии

Фаза `criteria`. Договоритесь, что включать, что исключать и на какие **категории** делить корпус. Они сохраняются через `review_criteria` и становятся кластерами сводки.

## 3. Поиск

Фаза `search`. Claude вызывает `search_papers` по каждой теме из критериев; результаты сохраняются как `unreviewed`, в чат возвращаются только заголовки, без абстрактов. Можно также `import_refs` из экспорта `.bib` / `.ris`.

## 4. Ревью

Фаза `review`. Claude берёт из `next_step()` пачки по 20 компактных записей, решает по каждой (approved / maybe / rejected с оценкой уверенности) и отправляет одним вызовом `review_batch`. У одобренных и «может быть» статей есть заметки `claim` / `finding`. До вас доходят только пограничные, по одной:

```
Статья 7/87: «Название» (2023, Авторы)
Кратко: ...
Почему пограничная: ...
включить / исключить / может быть?
```

После каждой пачки Claude переписывает скользящую сводку (`review_summary`); следующая пачка не выдаётся, пока этого не сделано.

## 5. Подтвердить неуверенные решения

Фаза `low_confidence`. Каждое решение `auto_low` проходит через вас до синтеза.

## 6. Синтез

Фаза `synthesis`. Claude читает заметки по кластерам и фиксирует пробелы, противоречия, консенсус и открытые вопросы — каждый с привязкой к исходным заметкам.

## 7. Письмо

Фаза `done`: корпус готов. Claude предлагает структуру (`create_sections`), затем по каждой секции пишет черновик, критикует и правит. С плагином `academic-writing` он следует научному русскому и, для отчёта, структуре ГОСТ 7.32. Итоговый документ (Word, Typst, LaTeX, Markdown) вы собираете в привычном формате; `export_bibliography` даёт `.bib` и соответствие `[N]` → ключ цитирования.

## После `/clear` или в новой сессии

Сначала `next_step()`. Он несёт фазу, счётчики и данные для неё — ничего не потеряно.
