# snowcite

MCP-сервер и skills для систематического обзора литературы. Поиск по arXiv / Semantic Scholar / OpenAlex / Crossref / PubMed, snowballing по цитированиям, отбор статей в чате, граф заметок и синтез между статьями. Текст пишет сама модель по skills — snowcite не собирает PDF.

!!! info "Без UI и браузера"
    Ревью идёт в чате. Claude читает компактные записи пачками, сам отсеивает очевидное и приносит вам только пограничные случаи.

## Чем отличается

- **Рельсы в сервере, процедура в skills.** `next_step()` выводит фазу из базы и возвращает, что делать и с какими данными. Ограничения проверяются кодом: следующая пачка ждёт сводку, неподтверждённые решения с низкой уверенностью блокируют синтез, одобренная статья обязана оставить заметку в графе.
- **Граф знаний, а не список литературы.** Каждая одобренная статья оставляет заметки `claim` / `finding`; синтез добавляет поверх них прослеживаемые пробелы, противоречия и консенсус.
- **Секции с циклом критики.** Черновик по заметкам, критика строгим рецензентом, правка — остановка при нуле блокеров или после двух итераций.
- **Самостоятельные skills для письма.** Научный русский, рубрика рецензента и структура отчёта по ГОСТ 7.32 работают с snowcite и без него.
- **Проекты живут в каталогах.** `.snowcite/` рядом с файлами, как `.git`. Для смены проекта достаточно `cd`.
- **Маршрутизация источников по дисциплине.** STEM получает arXiv, медицина — PubMed, все — OpenAlex, Semantic Scholar и Crossref.
